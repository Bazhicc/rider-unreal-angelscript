# UE 调试验收

本轮暂不联调。以下条目均为待执行步骤，不代表真实 UE 已通过验收。
自动化测试使用本地模拟 UE socket，覆盖分片/合包、Unicode、异常消息长度、连接替换，
以及跨栈帧请求归属、继续后迟到回复、超时、断线和 LSP 资产编辑确认。

使用带 AngelScript 的 Unreal Editor、可正常编译的 `.uproject`，
在 Rider 沙箱安装当前 ZIP，并使 UE 与插件的 host/port 一致。
准备两个会相互调用的脚本函数，各自定义同名局部变量并赋不同值，便于识别栈帧结果。

| 操作 | 应观察到的结果 |
| --- | --- |
| 在可执行行添加断点并运行 PIE | 命中位置、调用栈与源码一致；局部变量和行内值正确。 |
| 在空行添加断点，再修改脚本并保存 | 断点调整到 UE 确认的位置或显示无效；重编译后重新同步。 |
| 在两个栈帧间快速切换，展开变量并添加同名 watch | 每个结果属于发起请求的栈帧；没有串值、永久加载或异常。 |
| 连续执行继续、暂停和单步 | 旧行内值及时清除，新暂停位置显示新值；旧回调不能恢复旧栈。 |
| 编辑正在调试的脚本并触发热重载 | 未保存时断点失效，编译完成后重新同步；异常编译诊断仍到达 Rider。 |
| 关闭 UE 后重开，分别测试自动重连开/关 | 开启时恢复连接并同步断点；关闭时停止会话。状态栏显示对应类型加载状态。 |
| 在连接、暂停、变量加载阶段分别停止调试或关闭 Rider 工程 | 不再自动重连，不再更新该会话，不残留监听器或 AngelScript 连接线程。 |
| 重复附加和停止至少三次 | 一次文档改动只触发当前会话处理，没有历史会话重复日志。 |
| 从 UE 修改脚本资产定义；另测编辑被拒绝 | 成功应用后才保存；失败显示原因，没有保存未应用的编辑。 |

记录 Rider/插件/UE 版本、工程路径、操作及结果；失败时附 Rider `idea.log`、UE 日志和
插件调试日志。性能比较应使用同一工程、相同索引状态及相同操作，分别记录首次与缓存命中耗时。
