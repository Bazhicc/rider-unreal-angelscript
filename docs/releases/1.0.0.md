# Unreal AngelScript for Rider 1.0.0

This release integrates Clang-Format into the main plugin and restores complete native and semantic highlighting through Rider's C++ color scheme. It replaces the previous `1.9.4-rider.29` release; the bundled language server remains based on Hazelight 1.9.4.

## Highlights

- **Integrated formatting:** bundled Clang-Format 21.1.8, full-file and selection formatting, on-type formatting, project style overrides, saved Rider C++ brace preferences, and optional EditorConfig rules. AngelScript-specific syntax and strings are protected, with Unicode-aware replacement offsets.
- **Native highlighting without TextMate:** the TextMate dependency and grammar bundle have been removed. Rider's Kotlin lexer, PSI, and native color system provide highlighting even before the language server connects.
- **Rider C++ colors:** native and language-server highlighting share the active C++ scheme and user customizations. Fixed AngelScript palettes have been removed, and C++ fallback relationships resolve before backend semantic-key registration.
- **Restored and extended color coverage:** functions, methods, classes, variables, parameters, namespaces, Unreal macros and reflection specifiers, struct fields, enum types and values, raw strings, valid and invalid escapes, documentation commands, and resolved overloaded operators use their corresponding C++ categories.

Existing completion, diagnostics, navigation, references, rename, Unreal debugging, and C++ Find Usages integration remain available. See the [README](https://github.com/Bazhicc/rider-unreal-angelscript/blob/v1.0.0/README.md) for requirements and configuration.

## Upgrade and configuration

1. Download **`UnrealAngelscript-1.0.0.zip`** from this release's assets.
2. In Rider, select **Settings | Plugins | Install Plugin from Disk**, choose the ZIP, and restart Rider.
3. Disable other plugins that register AngelScript files. Remove or disable the standalone **Unreal AngelScript Clang-Format** plugin; its functionality is now included here. TextMate Bundles is no longer required.
4. Customize colors under **Settings | Editor | Color Scheme | C++**. Some schemes intentionally use the default foreground for local variables or ordinary operators.
5. Configure formatting under **Settings | Tools | AngelScript Clang-Format**. Project `.clang-format` files override the bundled style. Use `ReferenceAlignment: Left` when references should format as `Type& Name`.

Requires Rider 2026.1 (build `261.25134` through `261.*`) and Node.js 22+. JDK and .NET SDK installations are needed for building the plugin, not for installing it.

## Validation

- The full local JVM suite passed: **164 tests, no failures, errors, or skipped tests**, including formatter and optional UE source regression checks.
- All **9 language-server tests** and the native C++ usage-search backend harness passed.
- Highlighting checks verify resolved C++ foreground colors and pixels rendered by a Rider SDK editor, with TextMate disabled.
- Plugin Verifier reported compatibility with the installed Rider 2026.1 build; existing deprecated and experimental API warnings remain.
- The release workflow builds and tests on Windows and Linux, checks plugin structure, and runs Plugin Verifier on Linux before publishing the ZIP.

Automated editor rendering does not replace hands-on Unreal debugging and project navigation validation.
