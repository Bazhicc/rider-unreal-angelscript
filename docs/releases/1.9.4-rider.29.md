Unreal AngelScript for Rider 2026.1。

## 更新内容

- 修复 GitHub Actions 在 Rider 2026.1.3 SDK 下无法解析 `LspClient*` API 的编译错误，保留对新版 Rider LSP 服务注册方式的兼容。
- 包含 AngelScript 语法高亮、Kotlin lexer/parser/PSI、LSP 补全与导航、引用搜索、重命名、调试和格式化支持。
- 包含 UE/C++ 源码导航及原生 C++ Find Usages 中的 AngelScript 引用集成。
- 包含格式化字符串解析，以及 C++ CRLF/UTF-16 跳转位置修复。

## 安装

1. 准备 Node.js 22 或更新版本。
2. 下载本页附件 `UnrealAngelscript-1.9.4-rider.29.zip`。
3. 在 Rider 的 `Settings > Plugins > 齿轮 > Install Plugin from Disk` 中选择该 ZIP，安装后重启 Rider。

支持 Rider 2026.1（构建范围 `261.25134` 至 `261.*`）。安装时不需要单独安装 JDK 或 .NET SDK。
功能说明、配置方式及验证范围见[项目 README](https://github.com/Bazhicc/rider-unreal-angelscript/blob/v1.9.4-rider.29/README.md)。
