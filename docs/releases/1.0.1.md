# Unreal AngelScript for Rider 1.0.1

This release fixes false syntax errors in valid Unreal AngelScript code and updates the plugin description and setup information.

## Changes

- Recognize `#ifdef` and `#ifndef` using the existing conditional-branch PSI, including nested branches.
- Preserve escaped quotes in single- and double-quoted strings, including default parameters, name/text literals, and strings inside interpolation expressions.
- Keep string token boundaries and offsets stable when the editor restarts the lexer.
- Add regression coverage for nested conditional branches, missing `#endif` diagnostics, CRLF input, escaped string defaults, and lexer restarts.
- Update the plugin description to explain native syntax support, bundled tools, and which features require a running Unreal Editor or game.

## Validation

All 15 project probe scripts now parse without errors, down from 102 false syntax diagnostics. The project scripts were not modified.

- **166 JVM tests passed**, with no failures, errors, or skipped tests, including optional Unreal source regression checks.
- All **9 language-server tests** and the native C++ usage-search backend checks passed.
- Plugin packaging and structure checks passed.

These results cover automated parsing and integration checks; they do not constitute runtime validation of every probe script.

## Installation

Download **`UnrealAngelscript-1.0.1.zip`** from this release, then select **Settings | Plugins | Install Plugin from Disk** and restart Rider.

Requires Rider 2026.1 (build `261.25134` through `261.*`) and Node.js 22 or later. Existing plugin configuration is retained. See the [setup guide](https://github.com/Bazhicc/rider-unreal-angelscript#install-and-configure) for language-server, formatting, and debugger settings.
